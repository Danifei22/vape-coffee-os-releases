# VAPE & COFFEE OS — instaladores

Este repositorio no contiene código. Su único contenido son los instaladores de
Windows de VAPE & COFFEE OS, publicados en la pestaña **Releases**.

Es público por un motivo concreto: el programa se actualiza solo, y para
descargar una versión nueva tiene que poder hacerlo sin credenciales. Meter un
token dentro de una aplicación instalada en el ordenador de un cliente no es
guardar un secreto. Así que lo público es el instalador, que de todas formas se
manda a quien lo pide, y el código fuente sigue en un repositorio privado.

Para instalar, descarga el `.exe` de la última Release. El `latest.yml` y el
`.blockmap` que lo acompañan los usa la actualización automática; no hay que
descargarlos a mano.
